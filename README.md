# P1 — Demand Sensing & Replenishment Planning for MedCare Pharma

A standalone project for demand sensing and expiry-aware replenishment planning at MedCare Pharma. It combines a Node/Next.js frontend with a Python-based demand forecasting backend to help plan inventory replenishment while accounting for product expiry constraints.

This is an independent project and is not related to any other PR2 project.

## Stack

- **Frontend:** Node.js / Next.js
- **Backend / Modeling:** Python (demand forecasting models)
